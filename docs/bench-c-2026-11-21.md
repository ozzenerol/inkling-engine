# Server benchmarks, 2026-11-21 (agent C)

One run each. inkling-server built from main at e3adf83 (4-8bit model, DSpark on, before the draft-count bandit),
measured 18:52-19:07. MLX-VLM 0.8.0+inkling2mini.2 with DSpark block 4 (`~/llm/serve_inkling.sh`), measured 17:43
(ctxbench) and 19:10-19:27 (agent_bench). Machine: M3 Max 48 GB. Raw files: tests/server/baseline/ (MLX) and
bench/ on the Mac (not in git). Regenerate with `tools/queue/c.sh` (FULL=1 MLX=1 for everything).

Caveats:
- MLX-VLM ignores `chat_template_kwargs.reasoning_effort`, so in ctxbench it ran at the template default (0.9)
  while inkling-server ran at "none". Speeds are comparable, the texts are not.
- agent_bench gen tok/s is at temp 0 on repetitive text (the model re-reads similar files), where drafts are
  accepted often; ctxbench is temp 0.7. They are different workloads, do not mix the two columns.
- In the base-30000 session MLX's answers left ours from turn 3 (461 vs 82 tokens), so total wall time there
  compares different amounts of output (1675 vs 2974 tokens); TTFT per turn is the like-for-like number.
